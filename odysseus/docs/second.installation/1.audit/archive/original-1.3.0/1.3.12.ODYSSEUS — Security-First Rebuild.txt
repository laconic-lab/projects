### 1. The exact command that worked

This is the historical command from the installation transcript—not a request to run it again.

```
podman run -d \
  --name odysseus-chromadb \
  --restart unless-stopped \
  -p 127.0.0.1:8100:8000 \
  -v /home/deck/OdysseusProject/data/chromadb:/data \
  -e ANONYMIZED_TELEMETRY=FALSE \
  docker.io/chromadb/chroma:1.5.9@sha256:1e0b73a187a28757c572acba508c46f48c9e8b0acaf5c20e6d95cdedce1acdf6
```

The key is this line:

```
-p 127.0.0.1:8100:8000
```

Podman's port syntax is `HOST_ADDRESS:HOST_PORT:CONTAINER_PORT`. ChromaDB listens on port `8000` inside its container, while Odysseus connects to port `8100` on the host.
