4. Two architectural blockers to resolve
Blocker A — Actual container isolation

We must establish whether odysseus-box can operate without exposing /home/deck, sharing sensitive host identity access, or inheriting unnecessary host mounts.

We will inspect actual UID/GID mappings, mounts, capabilities and access paths. If the Distrobox arrangement cannot satisfy the security requirements, we must not pretend that Distrobox alone solves isolation.

Blocker B — Broker interfaces

The provider broker and project inspector must have narrow authenticated interfaces, fixed permissions, bounded inputs and outputs, and no arbitrary command execution.

The Agent must not be able to turn either service into a general-purpose host access mechanism.
