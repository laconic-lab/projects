The same mapping applies to GIDs.

### Important security consequence

Root inside a default rootless container maps to the Steam Deck user `deck`.

It is not host root, which is good, but it is not an independent unprivileged host identity either. If a container process running as root receives a bind mount containing files accessible to `deck`, it may be able to read or modify those files according to the host permissions.

This is especially important for Odysseus:

- The UI container must never receive the provider-key directory.
- A read-only mount prevents writes through that mount, but does not prevent reading.
- Separate containers alone do not prove that their host-side access is separated.
- We must validate whether alternative user mappings can provide a stronger boundary before finalizing the design.

The existing subordinate ID range gives us options to investigate, but we have not yet demonstrated that a suitable mapping works for this deployment.

### Existing Podman network

The existing `podman` bridge is:

## A5 — Check cgroup delegation and runtime security support

Before choosing container resource limits and isolation options, we need to establish what SteamOS delegates to the rootless user session.

STEAM DECK — Konsole / existing SSH session

```
echo "=== CGROUP V2 CONTROLLERS ==="
cat /sys/fs/cgroup/cgroup.controllers 2>&1

echo
echo "=== USER SESSION CGROUP ==="
systemctl show "user@$(id -u).service" \
    -p ControlGroup -p Delegate -p ActiveState 2>&1

echo
echo "=== USER CGROUP CONTROLLERS ==="
USER_CG="$(systemctl show "user@$(id -u).service" -p ControlGroup --value 2>/dev/null)"
if [ -n "$USER_CG" ] && [ -r "/sys/fs/cgroup${USER_CG}/cgroup.controllers" ]; then
    cat "/sys/fs/cgroup${USER_CG}/cgroup.controllers"
else
    echo "User cgroup controller file unavailable"
fi

echo
echo "=== PODMAN RUNTIME AND SECURITY SUMMARY ==="
podman info --debug 2>&1 | grep -iE \
'ociRuntime|runtime|cgroupManager|cgroupVersion|seccomp|apparmor|selinux|rootless|pasta|networkBackend'

echo
echo "=== PODMAN CONFIGURATION FILES (METADATA ONLY) ==="
for f in \
    /usr/share/containers/containers.conf \
    /etc/containers/containers.conf \
    "$HOME/.config/containers/containers.conf"
do
    if [ -r "$f" ]; then
        ls -l "$f"
    else
        echo "$f: absent or not readable"
    fi
done
```

This is read-only. It does not start containers, change cgroups, or modify configuration.
