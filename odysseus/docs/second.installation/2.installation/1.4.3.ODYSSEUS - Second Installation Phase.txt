3. What I want to preserve from the previous engineering
There are useful ideas in the recovery material:
- Separate START, STOP, STATUS and LOGS operations.
- Explicit container ownership checks.
- Graceful shutdown rather than indiscriminate container termination.
- Read-only log inspection.
- Separate provider architecture documentation.
- Explicit Python interpreter selection.
These operational principles are worth carrying forward.

However, the previous scripts must be reviewed against the new isolation architecture before any reuse.
