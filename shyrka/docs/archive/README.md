# Archived Shyrka Documentation Originals

The files in this directory are the original documentation sources retained unchanged during the Markdown conversion.

- These files are **historical reference copies**.
- They are not the active documentation entry points.
- Use the Markdown documents in the parent `docs/` directory for current navigation and presentation.
- Do not edit the archived originals as part of routine documentation maintenance.
- The archive does not imply that the recorded technical state remains current.

The conversion was limited to documentation format, presentation, internal reference links and additive schemas. No Steam Deck audit or runtime revalidation was performed.
