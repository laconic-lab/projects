## Maintenance rule

After every new test or accepted project decision, update the living audit's ledger, evidence, limitations, version number, change log, and continuation handoff. Before a material canonical revision, preserve the prior released version as an unchanged archive snapshot. Never mark a proposed command as executed. Do not repeat a completed test without documenting the changed condition and reason.
