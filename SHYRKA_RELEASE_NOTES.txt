2026-10-28 — Shyrka Granite generation-limit tuning
------------------------------------------------------------
Change classification:
- Maintenance configuration tuning; existing release numbering unchanged.
- Scope: the active Granite 4.1 8B generation-parameter profile used by
  Shyrka in localai-box.
- No agent tools, dashboard behavior, archive schema, or application
  source files were intentionally changed by this tuning.

Why this tuning was performed:
An earlier long answer ended mid-sentence. Inspection of the archived
conversation showed that the stored assistant message itself ended
incomplete, which made frontend-only truncation an insufficient
explanation for that particular response. The active Granite profile
contained num_predict=1024 and num_ctx=4096. The relatively low output
limit was identified as a plausible contributor, but the evidence did
not prove that it was the only cause.

Exact configuration change:
- Profile:
  /home/deck/LocalAIProject/config/granite-api-options.json
- num_predict: 1024 -> 4096.
- num_ctx: 4096 -> 4096 (unchanged).
- temperature: 0.3 (unchanged).
- top_k: 40 (unchanged).
- top_p: 0.9 (unchanged).
- repeat_penalty: 1.1 (unchanged).
- repeat_last_n: 64 (unchanged).
- seed: 42 (unchanged).

Explanation of the two settings:
num_ctx describes the context window available to the model for the
prompt and conversation context. num_predict limits the number of
tokens generated in an output. Both are now set to 4096 to make the
values easier to remember, but they are not interchangeable settings.
The configured output limit is a ceiling, not a promise that every
response will use that many tokens or finish every requested section.

Backup and change evidence:
- Pre-change profile backup:
  /home/deck/LocalAIAgentrecovery/patch-backups/granite-output-limit-20261028-065121/granite-api-options.json
- Pre-change profile SHA-256: a6bf00a178cb8250f458389dc8b1a345fc8200a19a907fa0fcaa11a79d551cd9
- The pre-change backup was checked for num_ctx=4096 and num_predict=1024.
- The active profile was read back and confirmed at num_ctx=4096 and
  num_predict=4096.
- Non-target settings were compared with the backup and found unchanged.
- This is evidence of configuration state, not proof of successful
  long-form generation.

Validation status:
CONFIRMED:

- Both requested numeric settings read back as 4096.
- Pre-change profile backup exists and contains the expected prior values.
- Other profile settings match the pre-change backup.
